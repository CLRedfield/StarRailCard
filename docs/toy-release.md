## 平台核验依据

- [Toy 官方介绍](https://www.bilibili.com/toy/intro)：支持静态互动作品上传，发布权限与审核以管理端为准。
- [B 站官方 Toy 仓库内容检查说明](https://github.com/bilibili/toy/blob/main/skills/toy/references/content-checklist.md)：使用相对资源路径；部署包只带构建产物；封面和图标分别上传；封面推荐 4:3 横图。**游戏竖屏与列表封面比例是两件事。**
- 用户确认上传包限额为 50 MB，因此打包脚本按严格的 50,000,000 字节执行 ZIP 与解压大小双重检查；超过上限时拒绝生成并保留上一份包。未登录平台提交审核。

## 运行边界

游戏无需自建后端。单人和本地养成不连接外部数据站；联机保留公共 MQTT 服务，最终能否在 B 站客户端连接，以 Toy 预览环境实际测试为准。存档保存在当前浏览器／WebView，换设备不会自动同步，可在设置中导出与导入。

适配竖屏触控，并继续支持横屏与电脑；默认亮色，主题切换只在首页。

本包使用联机协议 v2。双方更新后重新建房，旧 v1 房间与检查点不能续接；养成存档保留。选骰与攻防预览立即在本地更新，在确认、重投、换骰和战术等节点提交房主裁定。海瑟音额外引爆不消耗毒层，战斗逐次显示伤害来源及生命变化。

## 重新构建

```sh
npm run build
python scripts/package_toy.py
```

ZIP 内文件使用 `/` 路径分隔符，脚本检查入口、相对资源引用、原始素材完整性、映射后的每张图片与 ZIP CRC，并在 `release/package-manifest.json` 记录大小和 SHA-256。原始 `public/` 与 `dist/` 保留完整素材副本，Toy ZIP 去掉 65 份重复文件；首页 CSS 直接引用的原路径保留。以后修改源码后仍按上述两条命令重建。
