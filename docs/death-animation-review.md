## 实现与边界

`DefeatEffects.tsx` / `DefeatEffects.css` 依据以上可见特征重建像素 KO、红色文字立体层、粉红立方碎片、金白放射线、环形闪光和角色卡退场。像素字用 SVG 方块路径，不依赖设备字体；碎片由固定分布的 SVG 三面立方体组成。

演出由展示时钟管理，普通动作结算与受击结束后才进入 1700 ms 的 `defeat` 阶段，然后才交付最终结果状态。原卡的实际 DOM 位置通过 `data-battle-card` 测量，适应不同玩家和屏幕位置；原卡隐藏后，特效副本负责闪亮退场。减少动态效果时只显示静态 KO，跳过闪光、飞散和缩放。

这是网页环境中的重建，不是提取原版特效：原版的三维桌面镜头推近、卡牌/粒子真实几何、全部原始着色器以及结果页斜条转场并未逐帧复制。原片不能单独确认卡牌本体的具体破裂网格；这里采用短暂闪亮与不规则裁切退场作为衔接，不能把该裁切称作已验证的原版形状。

本次逐帧证据只直接验证了 4.0 普通对战击败敌人的 KO。共斗共享生命复起和首领换阶段使用同一击破表现、配合不同尾注，这是网页端的清晰反馈改编；没有把它们宣称为已验证的 4.2 原始演出。其触发由展示层区分，不以 `winner` 单一字段判断，避免漏掉复活或换阶段。
