# 实际音频与游戏事件对应

2026-09-28 接入版本。音频播放仅影响表现，规则随机种子和结算不读取音频状态。

| 场景 | 音效键 | 触发时刻 |
| --- | --- | --- |
| 开局、普通投骰、重投、曜彩投掷 | `roll` | 新的投骰事件呈现；同一批投骰只响一次 |
| 确认使用、确认交换 | `confirm` | 操作者的指令成功后；无效指令、AI、仅本地选择均不播放确认音 |
| 攻击、反击、反伤 | `attack` | 每一击卡牌飞行起始；减少动态效果时改在对应命中帧播放 |
| 海瑟音额外引爆、回合末中毒 | `poison` | 各次毒伤实际扣血的独立呈现帧；不叠加普通受击音 |
| 普通伤害、荆棘、瞬伤、生命消耗 | `damage` | 实际扣血时；完全防住的 0 伤害不播放受伤音 |
| 治愈 | `heal` | 实际恢复生命时 |
| 跃迁、骇入 | `arise`、`hack` | 变更骰面的表现帧 |
| 对局结果 | `win` | 新的结束状态首次显示 |
| 普通页面导航、交换、战术操作 | `click` | 轻反馈，避免将短时间大量操作替换为完整确认音 |

`BattleSoundTracker` 按对局标识及事件 ID 去重，不以日志中的最大 ID 代替实际播放记录。因此即使刃的重投事件先落地、较早编号的自伤随后呈现，也不会漏响或重播。重复网络快照、重连恢复、返回已有牌桌都不会补播旧伤害；完整和减少动态效果共用同一防重记录。

入口保留鼠标/触屏手势解锁，并补充 Enter、空格键操作解锁。音频资源、缓存、后台与音量管理由 `src/lib/audio.ts` 统一负责。

定向回归：`tests/battle-audio.test.ts` 覆盖全偶数被防住的海瑟音引爆与中毒、两次真实连击、完整/减少动态效果、重投自伤乱序、重复快照和恢复静音、确认与选骰分离。
