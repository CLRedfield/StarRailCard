# 网页版新手补给

新建养成存档发放 **6 战力币**。更新前的养成存档首次加载、或旧存档首次导入时，也会在原余额上一次性加 6 战力币。该补给是网页版为改善起步体验增加的便利功能，不属于原作发布配置，不修改原始关卡、商店价格或首通奖励。

## 金额依据

`src/data/shopGoods.json` 中，无资历及故事前置的战力币卡售价为 1、2 或 3 战力币。例如黄泉（商品 `1111`，3 币）、基层员工·安保（`1106`，2 币）、奇美拉（`1101`，1 币）合计 6 币；玩家可以按喜好选购开局阵容。

未额外发放战力粉尘、决胜战力币、绘彩战力币或资历。镀闪不影响通常的基础卡牌数值，粉尘不是开始挑战的必要条件；原有后续解锁仍按故事和资历进行。

## 存档与兼容

- `migrateProfile(profile)` 位于 `src/lib/storage.ts`，为新档、加载及导入的统一迁移入口。
- 可选字段 `starterSupplyVersion: 1` 记录已领取。缺少此字段的有效旧档在原币数上加 6；已有标记的档案直接返回，不再次加币。
- `createStarterProfile()` 和兼容入口 `newProfile()` 均内部调用该函数。旧版本 `newProfile()` 曾默认给 3 币；保存过的这类旧档更新后为原余额加 6，不重置余额。
- 原有库存、镀闪、完成关卡、资历、胜场和设置全部保留；导出的 JSON 包含领取标记，重新导入不重复加币。自由配置不重新领取，也不改变自由对局奖励规则。
- `isProfile` 接受没有标记的旧档和标记为 1 的新版档，拒绝未知补给版本或错误类型。

## 回归

`tests/progression.test.ts` 覆盖新档两个入口、旧档保留进度、重复迁移、导出再导入、导入字段校验、6 币实际购买三张开局卡、消费后不再领币、原始首通奖励及自由模式无额外奖励。
